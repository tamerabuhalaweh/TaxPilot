## A1. Vocabulary (normative additions to SRS §7/App. A)
Tenant, Client/Portfolio, LegalEntity, BusinessPresence (kind BRANCH/OFFICE/ESTABLISHMENT/OTHER; status NOT_ASSESSED/REVIEW_PENDING/REVIEWED), TaxObligationProfile (status UNKNOWN/NOT_REGISTERED/PENDING/REGISTERED/ENDED; exactly one subject), TaxRegistration (ciphertext + last4), TaxGroup (DRAFT/APPLICATION_PENDING/VERIFIED_ACTIVE/ENDED) + Membership (dated, non-overlapping), TaxContext (frozen hash + confirmer), JurisdictionCatalog (PLANNED/IN_REVIEW/BETA/ACTIVE/RETIRED), JurisdictionPack (versioned manifest + 9-operation interface). These MUST NOT be collapsed into one `country` column. Selecting a country asserts business context only.

## A4. Endpoints (full contracts in `OPENAPI-jurisdiction-proposals.md`)
`GET /jurisdictions`; `GET/POST /clients/{id}/legal-entities`; `PATCH /legal-entities/{id}`; `GET/POST /legal-entities/{id}/presences`; `GET/POST /legal-entities/{id}/tax-obligations`; `PATCH /tax-obligations/{id}`; `GET/POST /tax-obligations/{id}/registrations`; `GET/POST /clients/{id}/tax-contexts`; `GET /jurisdictions/{code}/capabilities?tax_type&date`; extended `POST /engagements` (`tax_context_id` required for tax work). Errors: `JURISDICTION_NOT_SUPPORTED / TAX_CONTEXT_REQUIRED / TAX_PROFILE_UNVERIFIED / PACK_NOT_APPROVED / CROSS_ENTITY_SCOPE_CONFLICT` (403/404/409/422 + actionable messages). Idempotent creates; server-derived tenant; same-tenant FK; masked registration reads.

## A5. Migration (JO-safe)
Forward migration adds tables/columns with nullable `tax_context_id` backfill: existing JO clients gain one LegalEntity (incorporation JO, base JOD) + one REGISTERED-or-DRAFT obligation per evident tax type + one confirmed TaxContext per open engagement after explicit user confirmation; engagements with issued reports keep legacy snapshot reference and never require reconfirmation to read. Down/roll-forward path documented in ERD doc. No default JO claim where context unknown — confirmation gate blocks rule runs until resolved. Dry-run on anonymized copy + row-count reconciliation required.
